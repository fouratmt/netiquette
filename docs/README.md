# Netiquette project documentation

This directory is the working source of truth for the Netiquette product. The
documents are intentionally short and should evolve with the product.

## Documents

- [Product requirements](./product-requirements.md) — product purpose, users,
  scope, experience, and success criteria.
- [Content and voice guide](./content-and-voice.md) — how etiquette entries are
  structured and written.
- [Technical architecture](./technical-architecture.md) — proposed Vue
  architecture, routes, data model, and engineering constraints.
- [Decision log](./decisions.md) — decisions already made and the reasoning
  behind them.
- [Implementation progress](./implementation-progress.md) — current state,
  milestones, and next work.
- [Open questions](./open-questions.md) — product decisions still being worked
  through with the project owner.

## Working method

When a decision is made:

1. Record it in `decisions.md`.
2. Update any affected requirements or architecture.
3. Remove it from `open-questions.md`.
4. Update `implementation-progress.md` when it changes the delivery plan.
